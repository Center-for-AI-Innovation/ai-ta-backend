# Migrate to Illinois Chat

We are in the process of migrating [https://uiuc.chat/](https://uiuc.chat/) to a the official campus supported instance [https://chat.illinois.edu/](https://chat.illinois.edu/).\
\
As part of this process we have disabled chatbot creation on [https://uiuc.chat/](https://uiuc.chat/) and encourage users to create new chatbots on [https://chat.illinois.edu/](https://chat.illinois.edu/).\
\
If you have a chatbot on the old instance [https://uiuc.chat/](https://uiuc.chat/) that you would like help migrating files from and to the new instance https://chat.illinois.edu/, please follow the following steps. We ask you to create a new chatbot on the new instance and we can help move the files over to the new instance. We will not be migrating the chat history.&#x20;

<br>

1. Create a new chatbot on [https://chat.illinois.edu/](https://chat.illinois.edu/) (does not have to have the same name as the old one
2. Fill out this [form](https://forms.illinois.edu/sec/944673135)
3. You can start customizing the new chatbot and add users to it
4. We will get in touch with you in the following two weeks to schedule file migration. We can help migrate all files if you would like or you can start from scratch

\
For any questions, please contact us at the support email [genaisupport@mx.uillinois.edu](mailto:genaisupport@mx.uillinois.edu). Thank you and happy chatting!
